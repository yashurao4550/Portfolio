# Yashu — Cybersecurity Portfolio

Personal portfolio website built with HTML, CSS and vanilla JS. Hosted free on GitHub Pages.

## Sections

- Home / Hero
- About
- Skills (Cybersecurity, Networking, Linux, Web basics)
- Projects
- Contact

## Run locally

Open `index.html` in a browser, or serve it:

```powershell
python -m http.server 8000
```

Then visit http://localhost:8000

## Deploy

Pushed to `main` branch — GitHub Pages serves it automatically from the repo root.
